PIM training videos and the evolution of reward

These videos show how the PIM reward drives goal-directed exploration before the agent has ever succeeded—and without any subgoals or curriculum.

r(st, at) = log pγπ(g | st, at)

g := (x, y, z) location of the block inside the bucket

iter 300

As the agent pushes the block away from the bucket, the reward drops.

iter 400

Near the end of the episode, pushing the block toward the right edge of the table slightly raises the reward.

iter 500

The agent still hasn't found a good strategy. It keeps exploring the left side of the table, but sliding the object toward the left decreases the reward.

iter 900

The agent slides the block toward the right edge of the table and the reward climbs—then falls once the gripper loses contact with the object.

iter 1200

This is the agent's first try at throwing. The reward peaks just before the throw, then spikes again after the block's z matches the goal z.

iter 1400

The agent earns high reward for throwing the object next to the bucket, but once the object gets stuck there the reward falls.

iter 1500

Here the agent almost learns the throwing strategy, but it is not fast enough to finish the task before the end of the episode. Still, it receives high reward because the block ends up very close to the goal.

iter 1900

Finally, the agent learns to throw the object into the bucket and receives high reward.
